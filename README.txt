TUDLO CEBUANO CORPUS WEBSITE

PREVIEW
1. Extract the ZIP file.
2. Open index.html in a modern browser (Chrome, Edge, Firefox, Safari).
3. The site is responsive and works locally; no internet connection or remote images are required.

FEATURES
- Single-page interface with working tab navigation: Overview, Corpus, Research Questions, Text Analyzer, About TUDLO.
- Search and category filter for corpus design/inventory items.
- Browser-only text analysis: approximate word/token count, character count, sentence count, and top 30 frequent words.
- Export text-analysis summary to .txt.
- No images, no external libraries, and no fabricated linguistic examples or results.

RESEARCH INTEGRITY
The site is based on “Development of TUDLO Cebuano Corpus in Mindanao” (May 2026). It presents the thesis proposal's design and research questions. It does not claim that the one-million-token target has been reached, and it does not invent actual corpus findings or record-level data. Replace or extend the corpus inventory once verified text files, source metadata, permissions, and token counts are ready. The browser analyzer is a simple utility and not a replacement for AntConc.

PUBLISHING
You can host the folder on a static hosting service. If you later need user accounts, a shared searchable database, or online corpus uploads, a backend and appropriate privacy/access controls will be needed.
